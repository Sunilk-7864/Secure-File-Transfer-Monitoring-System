# Project 1: Secure-File-Transfer-Monitoring-System
This project focuses on developing a Secure File Transfer Monitoring System designed to ensure data confidentiality and track <p>file movement across a system or network.
File transfers—both internal and external—pose significant risks including data leakage, unauthorized access, malware distribution, and insider misuse.</p>
<p>This Monitoring system provides:</p>
<p>.File transfer logging</p>
<P>.Unauthorizing file movement detection</P>
<p>.File intigirti verification</p>
